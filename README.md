# Ordinarius Lab — Kale OS pipeline UI

Open WebUI fork used inside **Kale OS** (from **MPRA-IDE**) for expert pipeline management.

![Kale OS](https://raw.githubusercontent.com/ATA-SAHIN/mpra-ide/main/kale-os.png)

**Paper:** [Ontario Tech Scholaris](https://ontariotechu.scholaris.ca/items/d357a2fb-3a12-4f14-8e62-c7f4d4d8ea9f)

This is **not** the Open WebUI product. Cloning this repo does not boot Kale OS.

**Stack:** Python, Svelte/Vite, Open WebUI as upstream, local Ollama / OpenClaw proxy in the full runtime.

- IDE: [mpra-ide](https://github.com/ATA-SAHIN/mpra-ide)
- Extension: [ordinarius-extension](https://github.com/ATA-SAHIN/ordinarius-extension)

Upstream: [open-webui/open-webui](https://github.com/open-webui/open-webui). See `LICENSE` in this tree.
